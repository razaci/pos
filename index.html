    Firmware and interrupt table

    READ returns the selected register. WRITE replaces it. ADD adds a value to it. Registers hold 12-bit unsigned values. An overflow returns a fault and preserves the old value. Each accepted instruction runs one CPU cycle.

    The Mercy Seat decodes accepted requests. The veil rejects raw access. During Cloud, requests dispatch by camp priority (east, south, west, north). During Fire, requests dispatch in arrival order. This dispatch policy is part of the simulation.
